## Scripts Used to Generate the Final VCF of Reference TEs

- **`running_mcclintock`** contains all commands used to run TEMP2 on all samples.
- **`making_location_files`** contains the scripts used to generate the location files required to run McClintock. The information used to generate these files was obtained from the One Code to Find Them All outputs.
- **`making_final_vcf`** contains the scripts used to combine the McClintock output files and generate the initial VCF.
- **`genotyping_reference_TEs`** contains the script used to genotype reference TEs by identifying presence and absence reads.
